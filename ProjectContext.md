# SteamInvValue — Project Context

## Project Overview

**SteamInvValue** следит за несколькими инвентарями Steam и считает, сколько они стоят:
цены берутся со Steam Community Market и сторонних торговых площадок, пересчитываются в
₽ / $ / USDT / BTC и складываются в историю, по которой видно движение стоимости. Ссылки
на профили хранятся в конфиге и читаются при старте, поэтому одна и та же настройка
обслуживает и консоль, и локальный веб-интерфейс.

**Platform**: .NET 10 (`net10.0`), Windows x64 (self-contained сборки)
**Language**: C# (ядро, консоль, веб), HTML/CSS/JS (страница), PowerShell (установщик)
**Domain**: Оценка игровых предметов / агрегация цен / desktop-утилита

> **Ключевое отличие от «оценщиков инвентаря»**: Steam платит во внутренний кошелёк, а
> сторонние площадки — живыми деньгами. Эти суммы считаются раздельно и никогда не
> складываются в одно число. Предметы, которые нельзя ни продать, ни обменять, в суммы не
> входят вовсе.

| Сборка релиза | GitHub Actions | Тег `v*` → сборка → релиз |

### Зависимости

**Ни одного NuGet-пакета.** Всё написано на BCL: `HttpClient`, `System.Text.Json`,
`System.IO.Compression`, `System.Globalization`. Это осознанное решение — программа
раздаётся как self-contained exe, и каждая зависимость утяжеляет архив, который и без
того весит десятки мегабайт.

## Architecture Overview

Три проекта: ядро со всей логикой и две обёртки поверх него — консоль и локальный
веб-сервер. Обёртки не содержат правил оценки, только ввод-вывод. Один и тот же конфиг,
кэш, отчёты и история используются обеими, поэтому прогон из консоли виден на странице и
наоборот.

```
                 ВНЕШНИЕ ИСТОЧНИКИ
   Steam Community        Площадки            Курсы           GitHub
   профиль/инвентарь   Skinport Waxpeer    ЦБ РФ            релизы
   priceoverview       Market.CSGO         CoinGecko
        |                    |                 |                |
        +--------------------+-----------------+----------------+
                                   |
                          +--------v---------+
                          |  SteamInvValue   |
                          |      .Core       |
                          |                  |
                          |  Valuator        |  оркестратор прогона
                          |  InventoryClient |  чтение инвентаря
                          |  Providers[]     |  цены площадок
                          |  CurrencyService |  ₽ / $ / USDT / BTC
                          |  FileCache       |  кэш ответов
                          |  Storage         |  отчёты и история
                          |  AppConfig       |  список инвентарей
                          |  Updater         |  самообновление
                          +---+----------+---+
                              |          |
                +-------------+          +--------------+
                |                                       |
       +--------v---------+                   +---------v--------+
       |  SteamInvValue   |                   |  SteamInvValue   |
       |      .Cli        |                   |      .Web        |
       |  steaminv.exe    |                   |  Minimal API     |
       |  отчёт, JSON/CSV |                   |  + index.html    |
       +--------+---------+                   +---------+--------+
                |                                       |
                +-------------------+-------------------+
                                    |
                    %LOCALAPPDATA%\SteamInvValue\
                      config.json    cache\    reports\    history\
```

### Принципы

1. **Ядро ничего не печатает и не знает про HTTP-сервер.** Оно принимает настройки,
   отдаёт `Report` и сообщает о ходе работы через callback `Action<string>`. Поэтому
   консоль и веб дают одинаковые цифры.
2. **Кэш обязателен, а не оптимизация.** Steam ограничивает запросы по IP и отвечает
   `429`; без кэша повторный прогон ломается. Кэшируются список игр, предметы, прайс-листы
   площадок и точечные цены Steam.
3. **Цена спрашивается только на то, что площадка примет.** Сторонним нужен обмен,
   Steam-маркету — признак `marketable`. Это и корректность итогов, и экономия лимита.
4. **Сеть — только по делу.** Проверка обновлений спрашивает разрешение один раз, никакой
   телеметрии нет, ключ Steam API не требуется и никуда не отправляется.
5. **Отчёт объясняет сам себя.** Каждое число подписано тем, что оно значит; неполный
   опрос, перебор игр вместо страницы профиля и непродаваемые предметы попадают в
   «Замечания», а не остаются в логе.

## Project Components

### 1. **SteamInvValue.Core**
**Type**: Class library
**Location**: `src/SteamInvValue.Core/`
**Purpose**: Вся логика — чтение инвентаря, цены, курсы, кэш, конфиг, история, обновления.

**Ключевые файлы**:

| `SteamInventoryClient.cs` | 242 | Чтение инвентаря, разбор `g_rgAppContextData`, перебор игр, backoff |
| `Loc.cs` | 188 | Русские и английские строки парами (`Loc.Pick`), переключение культуры |
| `AppConfig.cs` | 154 | Список наблюдаемых инвентарей и настройки, чтение и запись |
| `Updater.cs` | 152 | Версия сборки, проверка релизов, скачивание и подмена файла |
| `Models.cs` | 99 | `InventoryItem`, `Quote`, `PricedItem`, `Money`, `Report` |
| `Storage.cs` | 93 | Последний отчёт и история замеров |

| `KnownApps.cs` | 30 | 17 известных инвентарей для запасного перебора |

### 2. **Провайдеры цен**
**Type**: Реализации `IPriceProvider`
**Location**: `src/SteamInvValue.Core/Providers/`
**Purpose**: Единый контракт «дай цены на эти имена» поверх разных площадок.

| Провайдер | Игры | Комиссия продавца | Как берёт цены |
|-----------|------|------------------:|----------------|
| `SteamMarketProvider` | все, включая карточки `753/6` | 15% | По одному имени, адаптивная пауза |
| `SkinportProvider` | 730, 440, 570, 252490 | ~12% | Весь каталог одним запросом |
| `WaxpeerProvider` | 730, 570, 440, 252490 | ~6% | Весь каталог одним запросом |
| `MarketCsgoProvider` | 730 | ~5% | Весь каталог одним запросом |

Метод `CanSell(item)` решает, примет ли площадка предмет: сторонним нужен `tradable`,
Steam-маркету — `marketable`. `SteamMarketProvider` дополнительно ведёт бюджет запросов и
подстраивает паузу (`NextDelay`).

### 3. **SteamInvValue.Cli**
**Type**: Console application → `steaminv.exe`
**Location**: `src/SteamInvValue.Cli/`
**Purpose**: Команды, печать отчёта, выгрузка, самообновление.

```bash
steaminv add https://steamcommunity.com/id/nickname   # добавить инвентарь
steaminv                                              # оценить всё из конфига
steaminv list                                         # что под наблюдением
steaminv history                                      # как менялась стоимость
steaminv update                                       # обновиться до свежего релиза
steaminv --check                                      # живы ли источники цен
```

Строки вывода вынесены в `Text.cs` парами «русский / английский».

### 4. **SteamInvValue.Web**
**Type**: ASP.NET Core Minimal API → `SteamInvValue.Web.exe`
**Location**: `src/SteamInvValue.Web/`
**Purpose**: Локальный сайт на `http://localhost:5188` — список инвентарей, плитки итогов,
график истории, сетка предметов с фильтрами.

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET` | `/api/state` | Список инвентарей, итоги, настройки, версия |
| `POST` | `/api/profiles` | Добавить инвентарь и сразу посчитать |
| `DELETE` | `/api/profiles/{id}` | Убрать вместе с историей |
| `POST` | `/api/profiles/{id}/toggle` | Включить или выключить наблюдение |
| `POST` | `/api/profiles/{id}/refresh` | Пересчитать один |
| `POST` | `/api/refresh-all` | Пересчитать все включённые |
| `GET` | `/api/report/{id}` | Последний отчёт |
| `GET` | `/api/history/{id}` | Точки истории |
| `GET` | `/api/jobs/{id}` | Статус и лог текущего прогона |
| `PUT` | `/api/settings` | Правка настроек |
| `GET` | `/img/{*path}` | Прокси картинок Steam |

Страница `wwwroot/index.html` зашита в сборку ресурсом — иначе single-file exe остался бы
без неё. Файл на диске, если он есть рядом, имеет приоритет: так правится вёрстка без
пересборки.

### 5. **install.ps1**
**Type**: PowerShell-скрипт
**Purpose**: Установка одной командой `irm ... | iex` — выбор папки и состава, скачивание
релиза с прогрессом, запись каталога в `PATH`, удаление через `-Uninstall`.

⚠️ **Файл намеренно только ASCII и по-английски.** `.ps1` с кириллицей требует UTF-8 BOM
для Windows PowerShell 5.1, а этот же BOM ломает `irm | iex`.

### 6. **.github/workflows/release.yml**
**Type**: GitHub Actions
**Purpose**: По тегу `v*` собирает обе программы под `win-x64` (self-contained, single-file),
подставляет версию из тега и прикрепляет архивы к релизу.

### Данные пользователя

Ничего не хранится рядом с программой — всё уходит в `%LOCALAPPDATA%\SteamInvValue\`:

```
SteamInvValue/
├── config.json           # список инвентарей и настройки
├── cache/                # прайс-листы (30 мин), цены Steam (12 ч), инвентарь (30 мин)
├── reports/<steamid>.json    # последний полный отчёт
└── history/<steamid>.jsonl   # по строке на прогон — из них строится график
```

⚠️ В `config.json` может лежать cookie `steamLoginSecure` — это полноценный доступ к
аккаунту Steam. Файл не входит в репозиторий и не должен пересылаться.

⚠️ Клиент в `Http.cs` — один на всю программу, и ходит он не только в Steam, но и в четыре
площадки, за курсами валют и на GitHub. Поэтому cookie кладётся в `CookieContainer`,
привязанный к доменам Steam, а не в `DefaultRequestHeaders`: заголовок по умолчанию уходит на
каждый хост, и ровно так в 0.6.0 пропуск в аккаунт уезжал посторонним. Добавляешь что-то общее
для всех запросов — сначала убедись, что это безопасно для любого адресата.

## Build Configuration

### Локальная сборка

```bash
dotnet build                                          # всё решение
dotnet run --project src/SteamInvValue.Cli -- list    # консоль
dotnet run --project src/SteamInvValue.Web            # веб на localhost:5188
```

### Сборка как в релизе

```bash
dotnet publish src/SteamInvValue.Cli -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:DebugType=none -p:Version=0.3.0 -o out/cli
```

### Выпуск версии

```bash
git tag -a v0.4.0 -m "описание"
git push origin v0.4.0        # дальше GitHub Actions соберёт и приложит архивы
```

Версия живёт в теге: workflow передаёт её в `-p:Version=`, и `steaminv --version` показывает
именно её. Сборка из исходников без тега сообщает `0.0.0-dev`.

### В работе ⏳

      главный запас по скорости, пока не проверен из-за лимита запросов
- [ ] Порядок опроса Steam по оценке стоимости: дорогое первым, копейки в хвост

### Запланировано 📋

- [ ] Долгий кэш для дешёвых позиций: цена карточки не двигается неделями
- [ ] Автозапуск по расписанию для накопления истории без участия человека
- [ ] Переименование `SteamInvValue.Web.exe` в `steaminv-web.exe` либо команда `steaminv web`

### Известные ограничения ⚠️

- **Лимит запросов Steam — главное ограничение всей затеи.** Массовой выдачи цен нет,
  `429` прилетает уже на десятках запросов подряд, а на части сетей анонимные обращения к
  `/inventory/` ограничиваются почти сразу. Обходится cookie `steamLoginSecure` или прокси.
- **Запасной перебор игр знает только 17 инвентарей.** Когда страница профиля недоступна,
  инвентари других игр в отчёт не попадут; отчёт об этом честно сообщает.
- **Настройка `language` почти ни на что не влияет**: интерфейс показывает
  `market_hash_name`, который всегда английский, а локализованное `name` не используется.
- **Адаптивная пауза при постоянных `429` примерно на десятую часть медленнее**
  фиксированной: за отказ уже заплачено backoff, и осторожность сверху стоит времени.
- **Цена берётся по `market_hash_name`**, то есть по имени и износу. Редкий float или
  паттерн CS2 стоит дороже, чем показывает отчёт.
- **Нет Buff163, buy order и цен выкупа ботами** — у первого нет публичного API, второй
  требует запроса на каждый предмет поверх лимита, третьи площадки не публикуют.
- **Автоматических тестов нет.** Правила проверялись прогонами и симуляцией
  (подбор адаптивной паузы), но тестового проекта в репозитории нет.

## Glossary

| Термин | Значение |
|--------|----------|
| **Живые деньги** | Сумма по сторонним площадкам за вычетом их комиссии — то, что можно вывести |
| **Кошелёк Steam** | Сумма на Steam-маркете минус 15%; остаётся внутренним балансом |
| **Максимум всего** | Лучшая цена по каждому предмету среди всех площадок; смесь наличных и кошелька |
| **`market_hash_name`** | Каноническое английское имя предмета, по нему сопоставляются цены |
| **`tradable` / `marketable`** | Можно обменять / можно продать на Steam-маркете; без обоих предмет не считается |
| **appid / contextid** | Идентификаторы инвентаря: игра и раздел (`753/6` — карточки, `730/2` — CS2) |
| **Замер** | Один прогон оценки, строка в истории |
| **Слот бюджета** | Лимит имён, которые Steam опрашивается за один запуск (`--steam-budget`) |
