# SteamInvValue — наблюдение за инвентарями Steam

Следит за несколькими инвентарями Steam и считает, сколько они стоят: по Steam Community
Market и по сторонним площадкам, с пересчётом в ₽ / $ / USDT / BTC и историей изменения
стоимости. Ссылки хранятся в конфиге и читаются при старте приложения.

```
src/SteamInvValue.Core   ядро: конфиг, чтение инвентаря, провайдеры цен, курсы, история
src/SteamInvValue.Cli    консоль: список, оценка, история, выгрузка в JSON/CSV
src/SteamInvValue.Web    локальный сайт: список инвентарей, карточки предметов, график
```

## Установка

Одной командой в PowerShell — скачает последний релиз, положит куда скажешь и пропишет в `PATH`:

```powershell
irm https://raw.githubusercontent.com/XYphrodite/steam-inventory-value/main/install.ps1 | iex
```

Спросит папку (по умолчанию `%LOCALAPPDATA%\Programs\SteamInvValue`) и что ставить —
`cli`, `web` или обе. Без вопросов и с параметрами:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/XYphrodite/steam-inventory-value/main/install.ps1))) `
    -Path 'C:\Tools\steaminv' -Components cli -Quiet
```

То же самое можно задать переменными: `STEAMINV_INSTALL_DIR`, `STEAMINV_COMPONENTS`,
`STEAMINV_VERSION`. Ключ `-NoPath` не трогает `PATH`, `-Version v0.1.0` ставит конкретный релиз.

## Обновление

```powershell
steaminv update
```

Программа обновляет себя сама: скачивает свежий релиз, кладёт на место старого и продолжает
работать. Закрывать ничего не нужно и лишних окон не открывается — работающий exe нельзя
перезаписать, но можно переименовать, поэтому старый уезжает в `.old` и удаляется при
следующем запуске. Новая версия начинает работать со следующего запуска.

Проверять обновления приложение само по себе не будет — это запрос к api.github.com, которого
никто не заказывал. Консоль **один раз спросит разрешения** и запомнит ответ в поле
`checkUpdates`; веб-морда молчит, пока не поставишь галочку в «Настройках». Разрешённая
проверка ходит в сеть не чаще раза в сутки, результат лежит в кэше. Разово: `--update-check`
и `--no-update-check`. Текущая версия — `steaminv --version` и в шапке веб-морды.

Удаление — тот же скрипт:

```powershell
& ([scriptblock]::Create((irm <тот же url>))) -Uninstall          # файлы и запись в PATH
& ([scriptblock]::Create((irm <тот же url>))) -Uninstall -Purge   # ещё и настройки с историей
```

Установщик написан по-английски и только ASCII: `.ps1` с кириллицей требует UTF-8 BOM для
Windows PowerShell 5.1, а этот же BOM ломает `irm | iex`. Токен не нужен; если репозиторий
когда-нибудь снова закроют, установщик подхватит его из `gh auth token` или `GITHUB_TOKEN`.

Ставить можно и руками — архивы лежат на странице
[Releases](https://github.com/XYphrodite/steam-inventory-value/releases):

| Архив | Что внутри |
|---|---|
| `steaminv-cli-win-x64.zip` | `steaminv.exe` — консоль |
| `steaminv-web-win-x64.zip` | `SteamInvValue.Web.exe` — локальный сайт |

Сборки self-contained: .NET на машине не нужен, распаковал и запустил. Внутри по одному
файлу — страница веб-морды зашита в сборку ресурсом. Ставить никуда не надо, положи куда
удобно; чтобы вызывать `steaminv` из любой папки, добавь её каталог в `PATH`:

```powershell
[Environment]::SetEnvironmentVariable('PATH', $env:PATH + ';C:\Tools\steaminv', 'User')
```

Удаление — удалить exe и, если не нужны настройки с историей, папку
`%LOCALAPPDATA%\SteamInvValue`.

## Сборка из исходников

Нужен .NET 10 SDK.

```
dotnet run --project src/SteamInvValue.Cli -- add https://steamcommunity.com/id/nickname
dotnet run --project src/SteamInvValue.Cli                    # оценить все из конфига
dotnet run --project src/SteamInvValue.Cli -- list            # что под наблюдением
dotnet run --project src/SteamInvValue.Cli -- history         # как менялась стоимость
dotnet run --project src/SteamInvValue.Cli -- --check         # живы ли источники цен
```

Чтобы получить такие же exe, как в релизе:

```
dotnet publish src/SteamInvValue.Cli -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o out/cli
```

Релиз собирается сам: `git tag v0.1.1 && git push --tags` запускает
[workflow](.github/workflows/release.yml), который публикует обе сборки и прикрепляет
архивы к релизу.

Веб-панель:

```
steaminv web              # http://localhost:5188
steaminv web 5300         # на другом порту
```

Из исходников — `dotnet run --project src/SteamInvValue.Web`. Порт задаётся аргументом
команды или переменной `STEAMINV_URL`. В веб-морде
слева список инвентарей с текущей суммой, справа — плитки итогов, график истории, таблицы
по площадкам и играм, сетка предметов с фильтрами. Инвентари добавляются и удаляются прямо
там, настройки правятся в панели «Настройки» и пишутся в тот же конфиг.

## Конфиг

`%LOCALAPPDATA%\SteamInvValue\config.json`, создаётся при первом запуске. Другой путь —
ключ `--config` или переменная `STEAMINV_CONFIG`.

```json
{
  "profiles": [
    { "id": "76561198000000000", "name": "Основной", "input": "https://steamcommunity.com/id/nickname",
      "apps": [730, 753], "enabled": true }
  ],
  "steam": { "enabled": true, "budget": 400, "delayMs": 3500 },
  "language": "english",
  "interfaceLanguage": "ru",
  "autoRefreshMinutes": 0,
  "proxy": null,
  "cookie": null
}
```

* `id` — SteamID64, он же ключ отчёта и истории; проставляется сам при `add`.
* `apps` — ограничение по играм, `null` или пусто — все инвентари профиля.
* `enabled: false` — не трогать при массовой оценке, но не терять историю.
* `language` — язык названий предметов, который запрашивается у Steam (`english` / `russian`).
* `interfaceLanguage` — язык самого приложения, `ru` или `en`; пусто — берётся язык системы.
  Перебивается ключом `--ui` и переменной `STEAMINV_UI`, в вебе меняется в «Настройках».
* `autoRefreshMinutes` — в веб-режиме сам переоценивает инвентари не чаще этого интервала;
  `0` — только вручную.

Рядом с конфигом складываются результаты: `reports/<steamid>.json` — последний полный отчёт
(веб открывает его мгновенно, не дёргая Steam), `reports/<steamid>.prev.json` — предыдущий,
для сравнения замеров, `history/<steamid>.jsonl` — по строке на каждый прогон, из них
строится график и колонка «изм.».

## Что изменилось между замерами

```
steaminv diff            # по всем инвентарям
steaminv diff "Мой"      # по одному
```

История отвечает «сумма выросла на 300 рублей», а `diff` — почему именно: что появилось,
что пропало, где изменилось количество и куда поехали цены. Изменение раскладывается на две
части: **из-за состава** инвентаря и **из-за цен** — сумма этих частей всегда равна общему
изменению. В веб-панели то же самое показывает карточка «Что изменилось».

## Разовая оценка

Ссылка, которой нет в конфиге, считается как есть и никуда не сохраняется:

```
dotnet run --project src/SteamInvValue.Cli -- https://steamcommunity.com/id/somebody --no-steam
dotnet run --project src/SteamInvValue.Cli -- nickname --json report.json --csv items.csv
```

## Что считается

| Число | Смысл |
|---|---|
| **Живые деньги** | только сторонние площадки, по каждому предмету берётся та, что заплатит больше, за вычетом её комиссии |
| **Кошелёк Steam** | всё продано на Steam-маркете за вычетом его комиссии. Это внутренний баланс, вывести нельзя |
| **Steam, медиана** | то же, но по медианной цене реальных сделок за последние дни, а не по самому дешёвому лоту |
| **Steam, ценник** | сумма `lowest_price` — столько платит покупатель, до комиссии |
| **Максимум всего** | максимум по всем площадкам сразу. Смесь наличных и кошелька, поэтому под ним показано, сколько в каждой части |
| **По площадкам** | сколько выйдет, если продать на одной конкретной площадке всё, что она принимает |

Steam и сторонние площадки разведены намеренно: Steam платит во внутренний кошелёк, а не
живыми деньгами, и складывать их в одно число — врать самому себе.

**Есть ответ на вопрос «что продавать».** Отчёт-каталог говорит, сколько всё стоит, но
решение выглядит иначе: обычно небольшая часть позиций даёт почти все деньги, а остальное —
длинный хвост, где на каждую позицию нужен отдельный лот. Поэтому считается минимальный
набор, покрывающий 80% суммы, — с отсевом неликвида и с указанием, сколько позиций и денег
остаётся в хвосте.

**С карточки можно сразу пойти продавать.** Название предмета ведёт на его лот в
Steam-маркете, а каждая площадка в списке цен — ссылка: у Steam на страницу предмета, у
остальных на поиск по имени (их адреса предметов формируются по-своему и без гарантий).

**Медиана против самого дешёвого лота.** `lowest_price` — это цена конкретного лота прямо
сейчас, и её легко сдвинуть демпингом одного продавца. `median_price` — по чём предмет
действительно уходил за последние дни. Обе цифры приходят одним ответом, поэтому вторая
сумма считается бесплатно; в отчёте видно, для скольких позиций медиана известна — она
появляется по мере обновления кэша цен.

**Ликвидность видна отдельно.** Для каждой позиции показывается, сколько таких предметов
продалось на Steam-маркете за сутки. Цена без продаж — не деньги: предмет за 15 $, который
за сутки не купили ни разу, продать по этой цене не выйдет. Такие позиции считаются
отдельной строкой «Не продаётся» и фильтруются в веб-панели галочкой.

**«Нельзя пока» и «нельзя никогда» — разные строки.** Если Steam сообщил срок временной
блокировки обмена, предмет считается заблокированным временно и показывается отдельно с
ближайшей датой разблокировки: потом это снова деньги. Оговорка: срок приходит в
`owner_descriptions`, а их Steam отдаёт владельцу — при чтении чужого публичного инвентаря
поля может не быть, и тогда всё выглядит как раньше.

**Непродаваемое не считается.** Цена учитывается, только если площадка реально примет
предмет: сторонним нужен обмен (`tradable`), Steam-маркету — `marketable`. Что не проходит
ни там ни там, показывается отдельной строкой «Продать нельзя» и в суммы не входит. Ключ
`--count-unsellable` возвращает старое поведение.

Комиссии сторонних площадок заложены в коде (`PayoutRate` у провайдера): Skinport ~12%,
Waxpeer ~6%, Market.CSGO ~5%. Комиссия Steam считается точно ([SteamFee.cs](src/SteamInvValue.Core/SteamFee.cs)):
у него две комиссии, 5% себе и 10% издателю, и **у каждой минимум в один цент**. Поэтому
плоские «минус 15%» верны только для дорогих предметов: с продажи за 0,03 $ продавец
получает 0,01 $, то есть теряет треть. Для инвентаря с сотнями карточек разница
существенная.

## Источники цен

| Площадка | Игры | Как берём |
|---|---|---|
| Steam Market | все, включая карточки (753/6) | `priceoverview` по одному имени, жёсткий лимит запросов |
| Skinport | 730, 440, 570, 252490 | публичный прайс всего каталога одним запросом |
| Waxpeer | 730, 570, 440, 252490 | то же |
| Market.CSGO | 730 | то же |

Если площадка отказала (например, Skinport ограничивает частоту запросов и отвечает `403`),
берутся последние известные цены из кэша, даже просроченные, а в замечаниях пишется их
возраст. Полностью терять площадку из-за одного отказа — хуже, чем показать цены получасовой
давности.

Кэшируется в `%LOCALAPPDATA%\SteamInvValue\cache`: прайс-листы площадок — на 30 минут,
точечные цены Steam — на 12 часов, прочитанный инвентарь — на 30 минут. Последнее важно:
без него каждый повторный прогон снова читал бы инвентарь и упирался в лимит Steam.
Перечитать принудительно — ключ `--fresh`.

Цена спрашивается только на то, что площадка примет. Для большого инвентаря это разница в
разы: 116 запросов к Steam вместо 1028, потому что остальное непередаваемое.

## Про лимиты Steam

Это главное ограничение всей затеи:

* У Steam нет массовой выдачи цен — только по одному имени за запрос, и он отдаёт 429 уже
  на десятках запросов подряд. Поэтому по умолчанию: пауза 3.5 с, не больше 400 имён за
  запуск (`--steam-budget`, `--steam-delay`), экспоненциальный backoff на 429.
* Пауза подстраивается сама: заданная в настройках — стартовая, дальше она растёт на каждый
  429 и мелкими шагами снижается на серии удачных ответов, в границах от трети до полутора
  от стартовой. Найденное значение переносится в следующий запуск. На спокойном Steam это
  экономит около четверти времени, при постоянных 429 — примерно на десятую часть дольше
  фиксированной паузы: за отказ уже заплачено backoff, и осторожность сверху стоит денег.
* Что не влезло в лимит — попадёт в отчёт как «не опрошено». Запусти ещё раз: кэш
  накапливается между запусками, покрытие растёт.
* Инвентарь тоже лимитируется по IP, и на некоторых сетях (в частности на российских)
  анонимные запросы к `/inventory/` ловят 429 почти сразу. Лечится двумя способами:

  ```
  --cookie "<steamLoginSecure из браузера>"     # авторизованная сессия, лимит заметно мягче
  --proxy  http://user:pass@host:port           # или socks5://host:port
  ```

  Проще всего задать командой — она сразу сохранит его в конфиг:

  ```
  steaminv cookie "76561198...%7C%7C..."   # задать
  steaminv cookie                          # статус и подсказка, где взять
  steaminv cookie clear                    # убрать
  ```

  **На диске cookie шифруется** ключом твоей учётной записи Windows (DPAPI): в конфиге лежит
  строка вида `dpapi:AQAAAN...`, и на другой машине или под другой учёткой она бесполезна.
  От вредоноса, работающего под тобой, это не спасает — он попросит Windows расшифровать.

  Те же значения читаются из переменных `STEAMINV_COOKIE` и `STEAMINV_PROXY`, а в вебе
  задаются в панели «Настройки».

  **Cookie нужен не только против лимитов.** Сроки трейд-холда Steam отдаёт только
  авторизованной сессии, поэтому без него нельзя отличить «нельзя обменять неделю» от
  «нельзя обменять никогда» — проверено на живом инвентаре, строка со сроком не появляется. Cookie `steamLoginSecure` берётся из DevTools → Application → Cookies →
  steamcommunity.com; это полноценный доступ к аккаунту, так что никому его не показывай.
* Для скинов CS2 быстрее и полнее сторонние площадки: `--no-steam` даёт результат за
  секунды. Steam нужен в основном для карточек и всего, что не CS.

## Чего нет

* Buff163 — самая показательная площадка по CS2, но публичного API нет, нужны куки. Не
  подключал.
* Buy order (цена мгновенной продажи на Steam) — **недоступен**. Стакан заявок отдаётся
  только по внутреннему `item_nameid`, а Steam перевёл страницу лота на серверный React, где
  этого идентификатора больше нет: ни в HTML, ни в старом `render`-эндпоинте, ни в бандлах
  страницы — заявки подгружаются кликом уже из браузера. Доставать его — реверс-инжиниринг
  их SPA ради одной цифры. Вместо этого считается медиана реальных сделок.
* Мгновенная продажа ботам (обычно 40–60% от цены) — у площадок нет открытого прайса на
  выкуп, только листинги.
* Float/паттерны CS2 — цена берётся по `market_hash_name`, то есть по имени и износу.
  Редкий float или паттерн реально дороже, чем показывает отчёт.

## Приватность

Всё считается по публичным данным. Если инвентарь закрыт настройками — не увидит ни этот
инструмент, ни кто-либо ещё; ключ Steam API не требуется и никуда не отправляется.
